# Security policy

## Supported versions

Security fixes go into the latest release. AgentLoom is before 1.0, so earlier releases do not get them: upgrade to the newest one.

## Reporting a vulnerability

Do not open a public issue. Report it privately on GitHub, under **Security → Report a vulnerability**, or at <https://github.com/cchinchilla-dev/agentloom/security/advisories/new>.

Include what you can:

- the version, and how you installed it (PyPI, the Docker image, the Helm chart);
- a workflow, a snippet or the steps that reproduce it;
- what an attacker gains, and what they need to control first.

The conversation stays in the private advisory. Once a fix is released, the advisory is published, with credit to you unless you would rather not be named.
